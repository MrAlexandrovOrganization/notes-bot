# Notes для браузера и Telegram

Один Go/templ-фронтенд обслуживает браузер, веб-приложение на экране «Домой»
и Telegram Mini App. Он использует gRPC-сервисы Notes, напоминаний, поиска
и английского. HTTP и HTML нужны для браузеров и Telegram WebView.

## Открыть Notes

- В Safari с включённым VPN откройте `https://notes.mralexandrov.duckdns.org/`,
  войдите с паролем Notes и выберите «Поделиться → На экран „Домой“».
- В личном чате с ботом нажмите «Открыть Notes». Кнопка открывает `/mini`.
  При свежем подтверждении Telegram приложение входит автоматически.
  Тот же пароль Notes доступен в форме входа.
- Внизу находятся вкладки «Заметки», «Английский» и «Уведомления». Календарь,
  хранилище и дополнительные действия доступны в верхнем меню. Сайт
  использует системную светлую или тёмную тему.

Дневник, задачи, оценка и словарь общие с нативными клиентами. Оценка карточки
отправляется с серверным токеном текущего показа. Напоминания доставляет
существующий бот. Для работы веб-интерфейса нужны VPN и доступ к серверу.

## Доставка

Обычный образ `web` обслуживает сайт, `WEB_MOBILE_ONLY=true` оставляет
отдельный VPN-инстанс для нативного API. Caddy направляет `/mobile/v1/*`
на порт 18090, остальные пути на `notes-bot-web:8090`. Доступ к обоим
маршрутам проверяет действующее правило VPN.

В overlay Russia `NOTES_MINI_APP_URL` по умолчанию указывает на текущий HTTPS
вход `/mini`. Telegram при старте настраивает кнопку только для чата
`ROOT_ID`. Веб-вход проверяет подпись Telegram с уже используемым `BOT_TOKEN`,
срок, повтор входа и соответствие `ROOT_ID`. В обоих интерфейсах сайт выдаёт
защищённую веб-сессию. Бот-токен остаётся на сервере.

`make templ` обновляет локальные шаблоны. `make check` проверяет код и тесты.
Dockerfile веб-фронтенда собирает Tailwind и включает ресурсы приложения.

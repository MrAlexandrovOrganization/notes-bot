# Location в Grafana

12 ноября 2026 на рабочем экземпляре WSL создана папка `Location` (UID
`location`). В неё перенесены существующие `Location`, `Location · блэклист`
и ручной `Route Planning`; добавлен `Location · зоны и радиусы` (UID
`location-zones`). Публичный вход требует прежней авторизации Grafana:
`https://grafana.mralexandrov.duckdns.org/d/location-zones`.

Новый дашборд читает существующий read-only datasource Location
`eftexe5xy5hxca`. Приложение, зоны, точки GPS, правила и права datasource не
изменялись. Список мест и границы обновляются из БД. Пригодная точка — Android,
не скрытая, с пустым quality_reason и accuracy в (0,100] м; её возраст показан
отдельно. Это последняя пригодная точка, а не гарантия текущего местоположения.

Граница — замкнутая геодезическая ломаная из 360 сегментов. SQL использует
радиус Земли 6371000 м, как детектор Location. Порог выхода дополнительно
показан оранжевым. Grafana 12 применяет `view.zoom` как максимальный zoom в
режиме fit, поэтому заданы и `zoom=18`, и `maxZoom=18`. Масштаб выбирается по
слою порога выхода, не по далёкой GPS-точке.

SQL всех панелей выполнен через реальный datasource для двух сохранённых зон.
Для обеих окружностей проверены 361 вершина, замкнутость и расстояние каждой
вершины от центра: отклонение от радиуса менее 0,00001 м. Полигон между
вершинами имеет погрешность аппроксимации до 0,39 м при радиусе 10 км.
Проверены генерация, пакет наблюдаемости и регистрация в отдельном временном
каталоге с сохранением постороннего файла. Карта проверена в браузере.

Исходники, генерация и установка описаны в README. Grafana на WSL читает
`~/.monitoring/grafana-dashboards/Location/` через file provisioning. Обычный
деплой notes-bot на Russia не доставляет эти файлы на WSL. В этом изменении
обновлены только ресурсы Grafana, приложения не пересоздавались.

## Результат переноса и ограничение

Перенос файлов с прежним `disableDeletion=false` пересоздал внутренние записи
Location и блэклиста: история их прежних редакций сбросилась. Восстановить её
из сохранённых JSON и свободных страниц SQLite не удалось. Текущее содержимое
обоих дашбордов сверено с копией до переноса; UID, URL и избранное сохранены.
История Route Planning не затронута. Копия исходных файлов и API-моделей
лежит на WSL в приватном каталоге
`~/.local/state/grafana-location-20261112T011005Z/`; он не включён в Git.

Перед последующими перемещениями между каталогами сохранять согласованную
резервную копию всей БД Grafana, а не только JSON. Не удалять старые файлы при
активном провайдере с удалением: сначала временно запретить удаление у
провайдера и применить настройку, затем переместить ресурсы и сверить ID,
историю и избранное. Не восстанавливать старую БД поверх текущей: это затрёт
последующие изменения других дашбордов.

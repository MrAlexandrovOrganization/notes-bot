# Android Frontend (Notes)

Native Android-клиент (Jetpack Compose + gRPC) для заметок — тот же набор
функций, что у web-фронтенда: день (заметка/оценка/задачи), календарь,
напоминания (в т.ч. из текста через LLM), поиск, RAG-вопросы и обзор файлов.

Общается напрямую с тремя бэкендами по gRPC:

| Сервис | Порт по умолчанию | Что даёт                        |
|--------|-------------------|---------------------------------|
| core   | 50051             | заметки, задачи, оценки, файлы  |
| notifications | 50052      | напоминания (user_id = ROOT_ID) |
| search | 50054             | поиск, открытие заметки, Ask    |
| Ollama (HTTP) | 11434      | разбор напоминаний из текста    |

## Сборка

Нужен JDK 17+ и Android SDK (compileSdk 36, minSdk 35). Откройте папку
`frontends/android` в Android Studio или соберите из консоли:

```bash
cd frontends/android
./gradlew :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Подключение к бэкендам

1. **Пробросьте gRPC-порты наружу** (в обычном compose-файле они не
   публикуются). Из корня notes-bot:

   ```bash
   docker compose -f docker-compose.yml -f frontends/android/docker-compose.android.yml up -d
   ```

   Это опубликует `50051`, `50052`, `50054` на хосте. Обратите внимание: gRPC
   тут без TLS, так что делать это стоит только в доверенной сети.

2. **Укажите адрес бэкендов** в `app/src/main/res/values/strings.xml`:
   - эмулятор: `10.0.2.2` (адрес хоста из эмулятора, стоит по умолчанию);
   - физический телефон: IP вашей машины в локальной сети
     (например `192.168.1.20`), и порты должны быть доступны с телефона.

3. **Ollama для «напоминания из текста»**: в `strings.xml` также указывается
   `llm_host` / `llm_port` / `llm_model`. Ollama в `backends/ollama`
   опубликован только на `127.0.0.1`, поэтому из эмулятора он доступен как
   `10.0.2.2:11434`, а с физического телефона — только если вы пробросите порт
   на сеть (например, через SSH-туннель или поменяв `ports:` у Ollama).

4. **`user_id`**: напоминания в сервисе notifications скоупированы по
   `user_id`. Чтобы видеть те же напоминания, что в Telegram/web, укажите в
   `strings.xml` строку `user_id`, равную `ROOT_ID` из `.env`.

## Структура

```
frontends/android/
├── app/src/main/proto/          # vendored proto (notes, notifications, search)
├── app/src/main/java/com/example/notes/
│   ├── data/grpc/               # gRPC-клиенты (Core, Notifications, Search)
│   ├── data/llm/                # HTTP-клиент Ollama (разбор напоминаний)
│   ├── ui/screens/              # экраны Compose
│   ├── util/                    # даты, формат ошибок
│   └── MainActivity.kt          # нижняя навигация (6 вкладок)
├── docker-compose.android.yml   # проброс gRPC-портов (для разработки)
└── README.md
```

Прото-файлы продублированы в `app/src/main/proto`, чтобы приложение собиралось
независимо от серверной части. Обновите их при изменении `proto/*.proto`
(приложение использует подмножество методов: см. `data/grpc/*Client.kt`).

## Особенности

- День: заметка, оценка 0–10, задачи (добавление/переключение), дописать текст.
- Календарь: месяц с понедельника, дни с заметками подсвечены, клик открывает день.
- Напоминания: список, создание (все 6 типов расписания), перенос
  (по длительности или на дату+время), удаление, создание из текста через Ollama.
- Поиск: по имени/содержимому (сервер выбирает ретриверы), открытие заметки и дописывание.
- Спросить: RAG-ответ по заметкам (сервис search, AskNotes).
- Файлы: обход каталога заметок, чтение файла, дописывание.

Отсутствует то, что не применимо к телефону/не переносится из ботов: голосовые
сообщения, геолокация и «умный» маршрутизатор intents (можно добавить позже).
